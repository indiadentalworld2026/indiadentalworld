**ASCI Guidelines for Dental Offers** — All promotional offers must (1) state the original price alongside the discounted price, (2) include a valid start and end date, (3) carry T&C including "subject to clinical assessment", (4) not use the word "free" for procedures that attract GST, and (5) not make comparative claims ("cheapest in Bengaluru") without substantiation. IDW auto-labels all offers as *Promotional Offer* in compliance with ASCI Code § 4.
